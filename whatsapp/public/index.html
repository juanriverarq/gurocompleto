📡 Endpoints de la API

Base URL: http://localhost:3000/api/v1

GET /whatsapp/status - Estado de conexión de WhatsApp
GET /contacts - Obtener lista de contactos
POST /contacts - Crear/actualizar contacto
POST /messages/send - Enviar mensaje
POST /messages/send-bulk - Enviar mensaje masivo
GET /messages/conversation/:phone - Obtener conversación
GET /automations - Obtener automatizaciones
POST /automations - Crear automatización
POST /automations/:id/execute - Ejecutar automatización
GET /whatsapp/stats - Estadísticas del servicio
